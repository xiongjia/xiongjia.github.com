# Hands-On Data Visualization Reading Plan

## Goal

Systematically read the free online book **《Hands-On Data Visualization: Interactive Storytelling from Spreadsheets to Code》**
(https://handsondataviz.org/) and build full-stack data visualization skills from spreadsheets to code:

- Find, question, and clean data (Google Sheets / OpenRefine)
- Chart, map, and table design principles and tools (Google Sheets / Datawrapper / Tableau Public)
- Embedding on the web (iframe) and customizing open-source code templates (Chart.js / Highcharts / Leaflet / GitHub)

Publish reading notes by chapter under `docs/notes/research/`.

## Tasks

- [ ] **Read: Choose Tools & Sketch Your Story (Ch1)**

  - Start Sketching Your Data Story, Ten Factors When Considering Tools
  - Tool selection checklist: Google Sheets / Datawrapper / Tableau Public / Observable
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Spreadsheet Skills (Ch2)**

  - Download to CSV/ODS, share Google Sheets, collect data with Forms
  - Formulas, pivot tables, XLOOKUP, spreadsheet vs relational database
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Find & Question Your Data (Ch3)**

  - Open data repositories, source your data, recognize bad data, question your data
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Clean Up Messy Data (Ch4)**

  - Smart cleanup with Google Sheets, extract tables from PDFs with Tabula, clean with OpenRefine
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Make Meaningful Comparisons (Ch5)**

  - Precisely describe comparisons, normalize your data, beware of biased comparisons
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Chart Your Data (Ch6)**

  - Chart design principles; Google Sheets charts; Datawrapper annotated/range/scatter-bubble charts; Tableau Public scatter & filtered line charts
  - Hands-on experiments + publish reading notes to `docs/notes/research/`

- [ ] **Read: Map Your Data (Ch7)**

  - Map design principles, choropleth colors & intervals, normalize choropleth data
  - Datawrapper / Google My Maps / Tableau Public point & polygon maps
  - Hands-on experiments + publish reading notes to `docs/notes/research/`

- [ ] **Read: Table Your Data (Ch8)**

  - Table design principles, Datawrapper table with sparklines
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Embed On the Web (Ch9)**

  - Static image vs interactive iframe, get & paste embed code or iframe tag
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Edit & Host Code with GitHub (Ch10)**

  - Copy/edit/host a simple Leaflet map template, GitHub Pages, repo & file management
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Chart.js / Highcharts Templates (Ch11)**

  - Bar, line, scatter, bubble, and error-bar chart templates
  - Hands-on experiments + publish reading notes to `docs/notes/research/`

- [ ] **Read: Leaflet Map Templates (Ch12)**

  - Leaflet with Google Sheets / CSV / open data APIs, storymaps, heatmap, searchable point maps
  - Hands-on experiments + publish reading notes to `docs/notes/research/`

- [ ] **Read: Transform Your Map Data (Ch13)**

  - GeoJSON, GeoJson.io, Mapshaper, KMZ→KML, Map Warper
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Detect Lies & Reduce Bias (Ch14)**

  - How to lie with charts/maps, recognize and reduce data & spatial bias
  - Publish reading notes to `docs/notes/research/`

- [ ] **Read: Tell & Show Your Data Story (Ch15)**

  - Storyboard narrative, draw attention to meaning, acknowledge sources & uncertainty, decide on format
  - Full-book summary + publish reading notes to `docs/notes/research/`

## Notes

- Book: Jack Dougherty & Ilya Ilyankou, *Hands-On Data Visualization: Interactive Storytelling from Spreadsheets to Code*
- Open-access web edition, free to read online, last updated 2026-06-01; built with Bookdown + RStudio
- Learning path: start with drag-and-drop tools (Google Sheets / Datawrapper / Tableau Public), then progress to open-source code templates (Chart.js / Highcharts / Leaflet)
- Hands-on focus: complete at least one full example each for charts, maps, and tables, and embed them in this site for demo
