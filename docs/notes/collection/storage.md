# :material-harddisk: Storage

## Object Storage

- [MinIO](https://github.com/minio/minio) - 高性能 S3 兼容对象存储（GNU AGPLv3 开源）
- [VaultS3](https://github.com/Kodiqa-Solutions/VaultS3) - 轻量 S3 兼容对象存储服务器（单二进制、内置 Web 面板、静态加密）

## File Hosting

- [CloudFlare-ImgBed](https://github.com/MarSeventh/CloudFlare-ImgBed) - 基于 Cloudflare 的自托管图床/文件托管（R2 / S3 / WebDAV 等）

## NAS

- [ClearOS](https://www.clearos.com/) - NAS 管理 Linux

## Backup

- [restic](https://github.com/restic/restic) - 快速、安全、高效的备份程序
