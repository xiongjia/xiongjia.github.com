# :material-monitor-dashboard: Frontend

## Tools / Frameworks

- [prettier](https://github.com/prettier/prettier) - 统一代码风格
- [lint-staged](https://github.com/okonet/lint-staged) - Git commit 时触发 lint
- [storybook.js](https://storybook.js.org/) - UI 组件文档生成
- [playwright](https://github.com/microsoft/playwright) - UI 自动化测试
- [hono](https://github.com/honojs/hono) - 轻量级 Web 框架
- [animejs](https://animejs.com/) - JavaScript 动画库
- [markdown-online-editor](https://github.com/nicejade/markdown-online-editor) - Markdown 在线编辑器
- [antvis/Infographic](https://github.com/antvis/Infographic) - AI 信息图生成与渲染框架（AntV）
- [Pele](https://pele.run/) - 轻量 Mermaid 图表转 SVG 渲染库（CSS 变量主题化）
- [tinyjsapp](https://github.com/tarwin/tinyjsapp) - 用 JS 构建原生应用（前后端一体，约 5MB）
- [CodeMirror](https://codemirror.net/) - 浏览器内代码编辑器组件（可扩展、支持语法高亮）
- [capacitor](https://github.com/ionic-team/capacitor) - 用 Web 技术构建 iOS / Android / Web 跨平台原生应用（Ionic）
- [aframe-vr-player](https://github.com/mysterion/aframe-vr-player) - 基于 A-Frame / WebXR 的 VR 视频播放器（PC 端串流到手机 Cardboard，支持 VR180/360）

- [awesome preact](https://github.com/preactjs/awesome-preact)
- [emotion-js](https://github.com/emotion-js/emotion) - CSS-in-JS
- [React Pro Sidebar](https://github.com/azouaoui-med/react-pro-sidebar)
- [jotai](https://github.com/pmndrs/jotai) - State management

- [dnd-kit](https://github.com/clauderic/dnd-kit) - React 拖拽排序 toolkit
- [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) - React 可拖拽调整大小的面板布局

## GUI Libraries

- [Dear ImGui](https://github.com/ocornut/imgui) - C++ 即时模式 GUI（无依赖、体积小）
- [egui](https://github.com/emilk/egui) - Rust 即时模式 GUI，native 与 Web 同一套代码
- [iced](https://github.com/iced-rs/iced) - Rust 跨平台 GUI 库（受 Elm 架构启发）
- [mygo](https://github.com/egoist/mygo) - 用 Go 开发桌面应用（原生 UI 或 Web 前端）
- [bellui](https://github.com/belluikit/bellui) - Go 跨平台 UI 工具包（Material Design 3 + WebGPU，Fyne 分支）
