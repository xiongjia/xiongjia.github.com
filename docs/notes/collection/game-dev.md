# :material-gamepad-variant: Game Development

> Indie game dev tools for 2D Metroidvania (Hollow Knight-like) development.
> All tools are free / open-source, zero-cost startup.

## Digital Painting — Krita

Practice: UI, brush engine, layer/mask, animation timeline.

- [Krita Official](https://krita.org/) - Open-source digital painting, alternative to Photoshop
- [Krita Docs: Getting Started](https://docs.krita.org/en/user_manual/getting_started.html)
- [Krita Docs: Tutorials](https://docs.krita.org/en/tutorials.html)
- [Krita YouTube](https://www.youtube.com/c/KritaPainting)
- [Krita Artists Community](https://krita-artists.org)

## Game Engine — Godot

The standard open-source 2D/3D engine, with native TileMap, Parallax, 2D skeletal system.

- [Godot Engine](https://godotengine.org/)
- [Godot Docs](https://docs.godotengine.org/en/stable/)
- [Your first 2D game (Dodge the Creeps)](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html)
- [2D Tutorials](https://docs.godotengine.org/en/stable/tutorials/2d/index.html)
- [GitHub: godotengine/godot](https://github.com/godotengine/godot)

Learning path:

1. Step by Step → 2. Your first 2D game → 3. 2D专题: TileMap, Parallax, 2D lighting, animation
