# part-0006 四阶段演进路线图（前段）

- **输入来源**: 本地 pdf 预提取文本（source-06.txt，arXiv:2606.05608v1 [cs.SE]）
- **原文链接**: <https://arxiv.org/html/2606.05608v1>

## 摘要

**§6 给出四阶段路线图（Table 3）**——基于当前能力与轨迹对 agentic engineering 演进的
分期（含人类角色与代表系统）：

| 阶段                         | Agent 能力                               | 关键技术                                               | 人的角色                      | 代表系统                         |
| ---------------------------- | ---------------------------------------- | ------------------------------------------------------ | ----------------------------- | -------------------------------- |
| I. Tool-Augmented            | 代码补全、单问题修复、简单脚本生成       | In-context learning、RAG                               | Author + reviewer             | GitHub Copilot、Claude Code      |
| II. Single-Task Autonomous   | 端到端功能构建、调试、基础系统维护       | Planning + tool use、self-correction                   | Intent architect + auditor    | Devin、OpenHands                 |
| III. Multi-Agent Teams       | 面向大型系统的协调 swarm、全生命周期管理 | Shared memory、role specialization、orchestration      | PM + architect + auditor      | LangChain orchestration、MetaGPT |
| IV. Self-Evolving Ecosystems | 自主发现、学习、再生产、适应             | Meta-learning、self-modification、ecosystem governance | Goal setter + ethics governor | AGI assistants（前瞻）           |

**§6.1 Stage I: Tool-Augmented（2023–2025）**——当前主导模式：agent 在人主导的工作流里当
助理。突破在编码：对范围明确的 task，模型能近专家级地生成、解释、调试代码。局限：人
仍须分解问题、设计架构、验证正确性。

**§6.2 Stage II: Single-Task Autonomous（2025–2027）**——agent 开始拥有从 specification
到部署的完整任务。Devin、OpenHands 这类系统能自主导航代码库、实现功能、提交 PR。人从
「做」转向「指定要做什么 + 验证做了什么」。

**§6.3 Stage III: Multi-Agent Teams（2026–2029）**——专门化 agent 组队协作，镜像人类工程
组织：「product manager agent」把业务需求转成技术规格、「architect agents」设计系统结构、
「developer agents」实现组件、「QA agents」测试验证。shared memory 与 observability 成为
关键基础设施。LangChain 试点是这一模式的早期验证（该段在 source-07.txt 续完）。

## 要点归纳

- 路线图的实质是**人的职责逐级上移**：作者/审阅者 → 意图架构师 + 审计者 → PM/架构师/
  审计者 → 目标设定者 + 伦理治理者
- 阶段时间窗口相互重叠（II 始于 2025、III 始于 2026），说明演进不是串行切换而是渐进铺开
- Stage I 代表系统即当下主流工具（Copilot / Claude Code），作者把「现在」也纳入谱系，
  让路线图具有「我们在哪里」的定位功能

## 术语 / 概念

- **Tool-Augmented / Single-Task Autonomous / Multi-Agent Teams / Self-Evolving
  Ecosystems（工具增强 / 单任务自主 / 多智能体团队 / 自进化生态系统）** — 四阶段命名
- **RAG（Retrieval-Augmented Generation，检索增强生成）** — Stage I 的关键技术
- **role specialization / shared memory / orchestration（角色专门化 / 共享记忆 / 编排）** —
  Stage III 的三根支柱
- **Devin / OpenHands / MetaGPT** — Stage II–III 的代表系统（自主 coding agent / 多智能体
  协作框架）

## 原句摘录

> Agents begin to own complete tasks from specification to deployment. Systems like Devin
> and OpenHands demonstrate that agents can autonomously navigate codebases, implement
> features, and submit pull requests. The human shifts from "doing" to "specifying what to
> do and verifying what was done."
