# ch-0014 Chapter 13: Transform Your Map Data

- **原书章节**: Chapter 13 Transform Your Map Data（pp. 357–392）
- **输入来源**: 本地 pdf（HandsOnDataViz.pdf）

## 摘要

做定制地图离不开地理空间数据。本章深入 **GeoJSON** 等格式，并介绍一套免费网页工具链，
在很多场景替代昂贵的 ArcGIS / 开源的 QGIS 桌面 GIS。

- **地理空间数据基础**：raster（栅格，如卫星影像）vs vector（矢量，点/线/面）；
  GeoJSON 是本书主推的开放标准矢量格式（基于 JSON），坐标顺序是 **longitude, latitude**
  （经度在前！）——这是最常见的坑
- **其他格式**：GPX（GPS 轨迹）、KML（Google Earth/2000 年代流行）、MapInfo TAB、
  Shapefile 等，都可能需要转成 GeoJSON
- **找边界数据**：从 OpenStreetMap（众包平台）下载 GeoJSON 边界文件（如城市、区域边界）
- **转换与绘制**：geojson.io——导入 KML/GPX/TopoJSON 转成 GeoJSON、绘制新要素并加属性
  （name 等）
- **编辑与连接**：Mapshaper——无绘图工具，但能按属性**连接**（join）表格数据到图层、
  简化几何、导出
- **地理配准（georeference）**：Map Warper——把历史静态地图图像配准到现代坐标，产出
  可叠加的瓦片层
- **批量地理编码**：US Census Geocoder 可免费批量处理美国地址；把逐点数据透视（pivot）
  成按区域（州/县/邮编）统计的多边形，用于 choropleth

## 要点归纳

- GeoJSON 是"地图数据的开放标准"，全章围绕它组织：找 → 转 → 画 → 连 → 配准 → 批量编码
- **坐标顺序经度在前（lon, lat）**，与直觉相反，出错率极高
- 矢量 vs 栅格决定数据能否缩放与编辑；本书聚焦矢量
- 工具分工：geojson.io（转换+绘制）→ Mapshaper（连接表格+简化）→ Map Warper
  （历史图配准）→ US Census（批量编码）→ 透视表 pivot 成多边形
- 这批免费网页工具明显降低了 GIS 门槛

## 术语 / 概念

- **GeoJSON** — 基于 JSON 的开放标准矢量地理格式（Point / LineString / Polygon 等）
- **raster / vector（栅格 / 矢量）** — 像素图像 vs 可编辑的几何对象
- **GPX / KML / Shapefile / MapInfo TAB** — 其他常见地理格式（GPS 轨迹 / Google 系 /
  Esri 系 / MapInfo 专有）
- **OpenStreetMap（OSM）** — 众包地图平台，可导出边界等矢量数据
- **geojson.io** — 在线查看/转换/绘制 GeoJSON 的免费工具
- **Mapshaper** — 在线简化几何、按属性连接表格到图层的工具
- **Map Warper** — 把静态历史地图 georeference 成可叠加瓦片
- **georeference（地理配准）** — 给图像指定地理坐标使其可叠加到现代地图
- **pivot（透视）** — 把点级数据按区域聚合，供 choropleth 使用
