# ch-0008 Chapter 7: Map Your Data

- **原书章节**: Chapter 7 Map Your Data（pp. 179–236）
- **输入来源**: 本地 pdf（HandsOnDataViz.pdf）

## 摘要

数据带空间维度时，地图能发展出更强的"地方感"。本章先讲地图设计原则，再分别用
Google My Maps、Datawrapper、Tableau Public 与 Socrata 平台做四种典型地图。

**设计原则**：区分点（point）与多边形（polygon）两类数据；choropleth（分区设色图）的
关键是把**归一化后**的数据按合理的颜色间隔（class intervals）映射到区域；配色要照顾
色盲读者；地图的底图（basemap）与上层数据层要协调。

**工具与地图类型**：

- Google My Maps：point map（点图，自定义图标/颜色），免费且易上手
- Datawrapper：symbol point map（符号点图，用大小编码数值）、choropleth（分区设色，
  内置分级与配色建议）
- Tableau Public：choropleth（可多级联动筛选）
- Socrata Open Data：current map——直接从开放数据 API 拉取实时数据、持续更新的地图

类型速查（Table 7.1）：point map、symbol point map、choropleth、heat point map
（热力点图）、story map（故事地图，见 ch-0013）、polyline map（路线）、customized
point-polyline-polygon（自定义组合）、searchable point map（可搜索点图）。

## 要点归纳

- 地图选型同样看"数据格式 + 故事"：点的位置 vs 区域数值 vs 路线 vs 密度
- **choropleth 三要点**：数据必须归一化（如按人口/面积）、颜色间隔要诚实、选对配色
  （考虑色盲友好）
- 点图适合"具体位置"（如医院），choropleth 适合"区域相对值"（如各州出生率）
- 用平台内置工具快速出图；更高级/更定制的地图等 ch-0012 的 Leaflet 代码模板
- current map 的"实时更新"理念：地图数据直接挂在开放 API 上（ch-0013 的 Leaflet
  Maps with Open Data APIs 模板延续此思路）

## 术语 / 概念

- **point map（点图）** — 用标记点表示具体位置
- **symbol point map（符号点图）** — 点的大小/颜色编码数值
- **choropleth map（分区设色图）** — 用彩色多边形表示区域数值
- **heat point map（热力点图）** — 用色带表示点密度/热度
- **polyline map（折线图地图）** — 表示路线（步道、通勤等）
- **story map（故事地图）** — 引导读者逐点游览、配滚动叙述的地图（ch-0013）
- **basemap（底图）** — 地图底层的瓦片图层（raster/vector）
- **class intervals（分级间隔）** — 把连续数值切成颜色区间的方式（ch-0001 提过）

## 原句摘录

> ...seeing the relative distance between points on a map, or identifying geographic
> patterns in a choropleth map (where colored polygons represent data values),
> relays information to readers' eyes more effectively than text, tables, or charts.

> ...remember that well-designed choropleth maps required normalized data and
> careful thought about color intervals.
