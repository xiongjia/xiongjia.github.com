# ch-0015 Chapter 14: Detect Lies and Reduce Bias

- **原书章节**: Chapter 14 Detect Lies and Reduce Bias（pp. 393–418）
- **输入来源**: 本地 pdf（HandsOnDataViz.pdf）

## 摘要

回扣开篇的收入不平等案例，给出判定可视化真伪的**三分法**：

- **wrong（错误）**：歪曲证据或违反硬性设计规则——如柱状图基线不从零开始、饼图扇区
  加起来超过 100%
- **misleading（误导）**：技术上合规、但有意引导误读——如对数刻度、截断基线、拉宽
  纵横比、加双纵轴
- **truthful（真实）**：数据准确且遵守规则；两个"同样真实"的画法可能并存（如 ch-0001
  两张世界地图）

**How to Lie with Charts**（引用 Mark Monmonier《How to Lie with Maps》的启发）：

- 截断基线夸大变化（把纵轴起点裁掉一大截，经济数据常见）
- 拉宽/压扁图表改变 aspect ratio 淡化或夸大趋势（引 Alberto Cairo 的建议：斜率约
  45° 时最利于诚实读图，但非普适）
- 加更多数据序列 + 双纵轴制造虚假关联

**How to Lie with Maps**：分类分桶（class intervals）的切法、投影方式、颜色选择都会
改变叙事。

**偏差（bias）**：定义为"不公平地偏向某一观点"。四类数据偏差：

- **sampling biases（采样偏差）**：selection / non-response / self-selection（ch-0006
  已预警）
- **cognitive biases（认知偏差）**：confirmation（只信符合先见的）、pattern（把随机数
  看成规律）、framing（同一事实换个说法：5% 死亡率 vs 95% 存活率）
- **algorithmic biases（算法偏差）**：系统放大既有特权，如司法再犯预测软件（Northpointe/
  Equivant）的种族偏差
- **intergroup biases（群体间偏差）**：群体刻板印象影响数据呈现与解读

四类**空间偏差（spatial bias）**：map area（眼球被大区域吸引——怀俄明 vs 罗德岛选举人票
案例）、projection（投影扭曲）、disputed territory（争议领土的呈现立场）、exclusion
（数据缺失区域的隐形）。

## 要点归纳

- 判定三步：wrong（违规）→ misleading（合规但误导）→ truthful（准确+合规）
- 图表说谎常用四招：截断基线、对数刻度、拉宽纵横比、双纵轴
- 地图说谎靠"分类/投影/配色"的选择——与 ch-0001 两张都"真实"的地图呼应
- 四类数据偏差 + 四类空间偏差，识别是减少的第一步
- framing bias 的经典例子：5% 死亡率与 95% 存活率是同一事实
- 反制手段：标注来源与不确定性（见 ch-0016）、不做选择性呈现、主动寻找反例

## 术语 / 概念

- **wrong / misleading / truthful** — 可视化真伪三分法（本书核心判定框架）
- **truncated baseline（截断基线）** — 纵轴不从零开始，夸大/掩盖差异
- **aspect ratio（纵横比）** — 图的宽高比；Cairo 建议接近 45° 斜率（非硬规则）
- **dual vertical axis（双纵轴）** — 两条量纲不同的曲线共轴，易制造假关联
- **confirmation / pattern / framing bias** — 确认偏差 / 模式偏差 / 框架偏差
- **algorithmic bias（算法偏差）** — 算法系统性偏袒某些群体（如司法预测）
- **intergroup bias（群体间偏差）** — 群体刻板印象造成的不公
- **map area / projection / disputed territory / exclusion bias** — 四类空间偏差

## 原句摘录

> ...if a bar or column chart begins at a number other than zero, it's wrong
> because those types of charts represent values through length or height, which
> readers cannot determine if the baseline has been truncated.

> The first map sorts nations in three categories... while the second map displays
> the entire range in a green-blue color gradient... Yet both maps are equally valid,
> because neither violates a definitive rule in map design nor intentionally
> disguises data.

> We define bias as unfairly favoring one view over another.
