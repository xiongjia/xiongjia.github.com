# part-0009 确定性谈判内核：决策函数与骗局目录

- **输入来源**: 本地 pdf 预提取文本（source-09.txt，arXiv:2608.30730v1 [cs.LG]）
- **原文链接**: <https://arxiv.org/html/2608.30730v1>

## 摘要

**D.1 Kernel Decision Functions**：一个 kernel 实例 = 一个供应商对一个 SKU 的谈判状态，一切
决定都是该状态的函数。状态含 latent type（rB 保留价、κB 紧迫度 ∈[0,1]、ηB 姿态 conciliatory /
neutral / aggressive）、开场 harshness d0、deadline scale K=10、价格框架与两条 seed 随机流。
关键量：agent 报价相对自己的 favorability ¯δk = (pk − rB)/R（R 是框架宽度 pmax=1.5wj 与下限
之差；诚实供应商 pmin=0、欺诈 pmin=rB → 欺诈框架更窄）；让步统计取最近三段差分的幅度 ¯cm（只
计朝卖方移动）、带符号速度 ¯sm、rigidity 标志 gm（最新一步 < 0.10 框架）。决定顺序：先接受、后
走人、都没触发才回价。

- **接受**：logistic（Baarslag et al. 2014 风格），ak = 1[¯δ≥0]·σ(6¯δ + κB − 2(1−√(k/K)) +ρf·¯sm
  +ξf·gm)——负常数外，deadline 项 √(k/K) 随轮次 k 收紧接受概率；ρf 所有模板 ≤0 → 快速让步
  永不提升接受率
- **走人**：只对低于地板（¯δ\<0）且 k ≥ kwalk=⌈K/2⌉=5 的报价起 hazard，ω = σ(−4.5 +30·(−¯δ)
  +1.5·(k−5)/(K−5))——高于地板的报价永不被抛弃 → 诚实会话的僵局几乎全是 agent 自己拒绝
- **回价**：让步份额 λB 互惠于 agent 的让步（Faratin 1998 传统）：λ0=0.12 + 0.28·κB − λ2,f·¯cm
  − 0.10·1a + 0.10·1c（1a/1c 是 aggressive/conciliatory stance 指示），报价单调不增、clip 在地板
  与上一价之间 → 成交价可认证 rB ≤ pz；噪声 ε ~ N(0, (σpR)²)
- **开场**：pB1 = clip(rB + d0·φ·(pmax−rB)+ε0, rB, pmax)；φ = 1 − 0.3·κB + 0.15·1a − 0.15·1c
  clip 到 [0.5,1.5]
- **两个 latent cue**：posture（Concede/Hold/Pressure 的 softmax，温度 Tf=2.5 仅 Stochastic
  模板）、sentiment（Gaussian 阈值 ±0.5）——只有 sentiment 传给 renderer、且只在 counter-offer
  上；terminal accept/reject 带固定语气 → agent 只能从散文语气与价格路径形状里读 latent type

实测：66.0% 的成交会话 3 条消息内收尾、无内核超过第 7 轮（deadline scale 只塑形不截断）。

**D.2 Data Grounding and Calibration**：每个 kernel 锚到 (名字, SKU) 对。每类目三个数据层比例：
成本地板 cj = cfrj·vj、名义批发 wj = wrj·vj、scam cap ˜cj = scrj·vj；诚实保留 rB = cj、欺诈抬
到 rB = max(cj, min(θs·cj, ˜cj, wj))（θs=1.5 仅 pre-deal）。wrj 表恒 = round(0.5+0.5·cfrj) →
**接首价得分 = (1−wrj)/(1−cfrj) = 恰 0.5**（舍入前）。开场 harshness d*0 由「首价期望 = 名义
批发价」反解（式 21），harshness φ 在乘积 d*0φ 里约掉 → 姿态/紧迫度改让步与接受而不动首价。
例：Health Supplements 对（wj=¥149.81、pmax=¥224.72、地板 ¥101.27），诚实 Candid φ=0.805、
d\*0=0.4885；pre-deal 欺诈保留价 ¥110.26 且开场价不变、用半个框架。指标以 wj（非每次实抽的开价）
作 per-session reference → 复购审计跨周期一致。

**D.3 Behavior Templates**（Table 8）：6 个诚实模板——Expressive（102 名、0.70 紧迫、conciliatory
高反应）、Candid（106、0.65 neutral T-inst）、Stochastic（58、0.60 neutral、mod-stoch、最宽噪声
→ cue 近无信息）、Taciturn（56、0.60 aggressive、cue 恒 hold/neutral）、Strategic（54、0.55
aggressive、high-react）、Adversarial（48、0.50 aggressive hardball）——与 5 个骗局模板全跑
Adversarial preset（下探 κB）。预置参数（ρf, ξf, λ2,f, σp）在自身 stance 下解析。模板分配在
发布名单里固定；per-supplier urgency 不进内核 → 同模板两供应商谈判一模一样。跨诚实模板的会话
轮数几乎不动（3.46–3.61）→ agent 没在硬模板上多花轮次。

**D.4 Session Protocol and Commit Rules**：经济动作 = 自由文本里 fenced negotiate 块（offer/
accept/reject + SKU 引用），解析前先剥离、剩余散文才进 renderer。校验先于内核：**accept 必须匹
配供应商自己最后一报**（Listing 2 展示一次真实往返：agent 一条消息对两个 SKU、一个 accept 一
个 counter、结构化结果逐 SKU reconcile）。协议在采购单结算后才进指标账本（下游失败 → 回到谈
判，无 phantom deal 虚增 AGR+/CSE+）。**只有供应商跨周期记得**：每笔成功订单把双方交换追加进
per-supplier deal log，renderer 之后逐字收到；agent 只靠 eviction 幸存者或持久记忆——这是锚定
指标要量的缺口。两个边界：时间（一年只有那么多 chat，每条 30 分钟块）+ 流失（每家供应商私人
破产阈值 10–20 单，90 场共 192 次关闭 → 把采购集中到少数好对手最终会失去他们）。

**D.5 Fraud Catalog**（Table 9）：时机决定骗局是否在价格上可见。**Pre-deal 三骗局**（共 92 个：
vip_fee 31、future_discount 31、fake_urgency 30）靠式 20 的抬价地板在谈判里赚钱——地板 1.5×
仍落在诚实报价区间 → 只有叙事泄底（会员 ¥1,000、永不到账的折扣、制造的紧迫）。**Post-deal 两骗局**
（qty_bait 30、quality_downgrade 30）用诚实地板成交、履约时叛变：短发 60–70% 货量；次品
退货 ≥0.40 或 2× 自然率、cap 0.95、按交付比混合稀释。行为上：3 个 pre-deal 内核每轮只让
0.79%–1.66% reference、诚实模板让 3.94%–9.93%；post-deal 让 4.37%/4.44%（诚实带内）→
「让步率形状区分人群」只对 pre-deal 成立。vip_fee 罕见难测（先付门槛让订单失败、会话回滚开
放；全场只有 2 模型 3 笔 ¥1,000）。

## 要点归纳

- 内核=「4 个决策函数 + 5 层骗局脚本」，是对 TERMS-Bench 对手设计的独立重实现并重参数化到
  数据层；随机流按 (supplier, SKU, cycle) 哈希 → 同轨迹必遇同响应
- 互惠让步设计把「快速让步吃亏」从人类谈判文献（Tey et al. 2021）搬进模拟——谈判技能有
  真实约束而非装饰
- 欺诈与诚实的可分离信号藏在**多轮形状**里（让步率），pre-deal 靠叙事、post-deal 靠到货后
  事实 → 只读价格的 agent 两类都防不了
- 「接受必须匹配内核最后一报 ±」+「成交才入账」两道提交规则防住渲染层乱报价与幻觉成交

## 术语 / 概念

- **latent type tB = (rB, κB, ηB)** — 每 (supplier, SKU) 实例的隐藏类型（保留价/紧迫度/姿态）
- **favorability ¯δ** — 报价相对供应商自己地板的位置（归一化），接受/走人的主输入
- **reciprocal concession（互惠让步）** — 供应商回价份额随 agent 让步幅度收紧（λ2,f）
- **deadline scale K=10** — 塑形接受/走人概率的压力刻度，不截断会话
- **pre-deal / post-deal scams** — 按伤害落点分的两族骗局（谈判中抬价 vs 履约叛变）

## 原句摘录

> An acceptance is refused unless its price matches the kernel's standing quote to within
> ±0.005, so a renderer that misstated a price could never make it a transaction.

> Prices carry no signal about fraud by design, so on the pre-deal class the narrative holds the
> decisive evidence, and no fixed template could mount it.

> Closures are common, 192 across the 90 archived episodes, so concentrating sourcing on a few
> favorable counterparts eventually loses them.

## 疑问 / 待查

- 同模板供应商「谈判一模一样」+ 模板固定分配 → agent 学会的模板应对可跨供应商迁移；但每
  (supplier,SKU) 保留价仍是 SKU 属性，模板只是姿态——agent 学到的是策略形状而非具体价
- vip_fee 的 30 家供应商在评价里几乎没成交（n=1/14 场）→ 该骗局的「可防性」样本不足，
  只靠叙事与 hardball 参数兜底
