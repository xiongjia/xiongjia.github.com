## 全书主线

15 岁的 Christopher Boone（自闭谱系特质、数学天才、只讲真话）在深夜发现邻居的狗
Wellington 被花园叉刺死，自己反被当成嫌疑人并获警诫。他不顾父亲禁令展开「侦探调查」，
却在过程中撞破一个更大的谎言：两年前「死于心脏病」的母亲其实没有死——她因无法承受
养育压力与邻居 Roger Shears 私奔去了伦敦，每周寄来的信全被父亲截藏。父亲随后向他
坦白：狗是他杀的（因被 Mrs. Shears 甩后嫉妒她「爱狗胜过爱他」）。Christopher 由此认定
撒谎者不可信，连夜出逃，独自乘火车到伦敦 Willesden 找到母亲；母亲带他回 Swindon，
让他照常考完 A-level maths（A 级）。结尾父亲用一只小狗 Sandy 开始重建信任，Christopher
的计划清晰展开：further maths → 物理 → 大学 → 当科学家——「我去过伦敦、解开谜案、
找到母亲、写了这本书，所以我能做任何事」。

主线按幕次展开（分幕明细与时间线见 [storyline.md](./storyline.md)）：

- **案发（ch 2–19）**: 发现狗尸 → 被警诫；交代主角设定（质数/首都/宇航员梦/宠物鼠 Toby）
- **侦探调查（ch 23–113）**: 逐户问询邻居、用演绎锁定 Prime Suspect = Mr. Shears；
  从 Mrs. Alexander 处得知母亲与 Mr. Shears 的婚外情；父亲暴怒、没收手稿
- **真相揭晓（ch 127–163）**: 在父亲卧室的衬衫盒里发现 43 封母亲来信 → 母亲未死、
  在伦敦 Willesden 与 Roger Shears 同居
- **坦白与出逃（ch 167–197）**: 父亲承认杀死 Wellington；Christopher 夜逃花园、决定
  独自去伦敦投奔母亲
- **伦敦历险（ch 199–227）**: 火车躲警察、地铁 5 小时煎熬、Toby 掉落轨道被救、
  深夜在 Chapter Road 与母亲重逢
- **和解与新起点（ch 227–233）**: 母亲带他回 Swindon 考完 A-level（A 级）；父亲以
  「5 分钟约定 + 小狗 Sandy」重建信任；Christopher 立志成为科学家

形式特色：全书 51 章全部以质数编号（ch 2 起，至第 233 章 = 第 51 个质数）；叙述中
大量穿插数学 / 天文 / 侦探方法论旁白，并以图表、footnote 等可视化 Christopher 的心智。
书中自始至终不出现 autism 等诊断标签，全部特征由叙述呈现。
