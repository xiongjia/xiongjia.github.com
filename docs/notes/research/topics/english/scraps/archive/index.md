# English Scraps Archive

归档按 **ISO 周**分文件（`scraps/archive/<YYYY-www>.md`，如 `2026-w33.md`），
卡片按条目 `date` 落进对应周文件；只在有归档的周生成，不强制每周都有。
查询用站内全文搜索；回顾用 `/skill:enu-organize quiz|review`。
完整流程见[使用指南](../index.md)。

## 字段说明

- `type`: `word` / `phrasal-verb` / `collocation` / `idiom` / `grammar` /
  `sentence` / `misc`（AI 判定）
- `status`: `new`（刚归档）/ `learning`（已导出 Anki）/ `mastered`（已掌握）
- `source`: 来源（可含 URL）；未知标「未知来源」
- `tags`: 从固定词表提取（technical / informal / formal / adjective / verb /
  idiom …，英文小写）
- `含义` + `英义`: 中文含义 + 英英释义（单词类卡片必填）
- `记忆`: 词根/词源/助记法（选填，简单词可不写）
