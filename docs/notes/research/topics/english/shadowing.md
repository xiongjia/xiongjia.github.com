# Shadowing

## 方案

- 每天 5–10 句、每句 5–10 次、总计 10–20 分钟
- **流程**：Listen → Listen again → Read transcript → Shadow → Record →
  Compare → Repeat
- **观察点**：
  - 音是否准确
  - 重音 / 节奏 / 停顿是否一致
  - 连读是否自然

## 素材两层

1. **第一层（兴趣驱动）**：Hollow Knight lore explained / full lore / story
   explained / analysis 等有清晰英语旁白的视频
1. **第二层（标准发音）**：BBC Learning English、VOA Learning English、
   English with Lucy、Rachel's English（避免只模仿一个 YouTuber 的口音）

具体素材清单收集在 [hollow-knight/resources.md](./hollow-knight/resources.md)。
