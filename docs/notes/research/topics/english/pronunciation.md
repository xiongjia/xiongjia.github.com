# 发音体系

三阶段：**Ear → Mouth → Rhythm**。

## Phase 1 — Ear（听辨）

**目标**：训练听辨元音、辅音、长短音、重音。

重点混淆对：

| 混淆对       | 区别要点    | 备注           |
| ------------ | ----------- | -------------- |
| ship / sheep | /ɪ/ vs /iː/ | 短音 vs 长音   |
| live / leave | /ɪ/ vs /iː/ | 短音 vs 长音   |
| full / fool  | /ʊ/ vs /uː/ | 短音 vs 长音   |
| rice / lice  | /r/ vs /l/  | 辅音对立       |
| west / vest  | /w/ vs /v/  | 辅音对立       |
| three / tree | /θ/ vs /t/  | 齿音 vs 齿龈音 |

## Phase 2 — Mouth（口型）

**原则**：一次重点解决一个音，优先 `th`、`r`、`l`、`v`、`w`。

- th（/θ/ /ð/）
- r（/r/）
- l（/l/）
- v（/v/）
- w（/w/）

易错音长期记录 → [pronunciation-mistakes-log.md](./pronunciation-mistakes-log.md)

## Phase 3 — Rhythm（节奏）

- **Word Stress** — 单词重音
- **Sentence Stress** — 句重音（内容词重读）
- **Weak Forms** — 弱读（如 `I want to go.` 不逐词等重）
- **Linking** — 连读
- **Reduction** — 弱化
- **Pausing** — 停顿
