# Pronunciation Mistakes Log

记录自己的易错音，长期维护。发现即记、定期复查。

## 记录格式

| 字段     | 说明                                  |
| -------- | ------------------------------------- |
| Problem  | 错的音 / 错的词（含 IPA）             |
| Reason   | 错误原因（母语干扰、口型、拼写误导…） |
| Practice | 练习方法（最小对、口型操、跟读…）     |
| Result   | 练习结果（日期 + 是否改善）           |
