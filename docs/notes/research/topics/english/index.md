# 英语学习

日常英语学习：随手收集碎片 + AI 归档整理；特殊阅读主题按需展开。

## English Scraps（主路径）

日常遇到生词 / 语法 / 难句 / 搭配，随手记一条，攒够一批让 AI 整理归档。
三个动作都在 **enu-organize skill**（`/skill:enu-organize`）下：

- 收集：`uv run poe enu add "内容"`，或 pi 里 `/skill:enu-organize add <内容>`
- 整理：攒够一批（inbox ≥ 15 条 / ≥ 2 周 / 主动）→ `/skill:enu-organize arch`
- 回顾：`/skill:enu-organize quiz [范围]` / `/skill:enu-organize review <tag>`

→ [Scraps 使用指南](./scraps/index.md)（完整流程、命令与文档位置）
