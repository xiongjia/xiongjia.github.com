# :material-function-variant: Algorithms

算法知识体系 —— 把「看起来神秘」的算法讲成**能自己推演的逻辑**：先讲它在
算什么、为什么这样算是对的，再讲工程上如何把它做得足够快。目标不是抄一份
实现，而是读到的人能随手在白纸上把这个算法重新推导出来。
