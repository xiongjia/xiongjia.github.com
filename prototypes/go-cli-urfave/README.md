# go-cli-urfave

Go CLI built with [urfave/cli](https://github.com/urfave/cli) — a minimal
experiment (originally under `research/experiments/`) validating the
urfave/cli framework while reading the [Lux](https://github.com/iawia002/lux)
video downloader source.

- Usage: `go run . --name <name>` (greets with `Hello, <name>!`)
- Created: 2026-08-03 · Status: `experimental`
